¿Qué es JavaScript? +

JavaScript es un lenguaje de programación interpretado, dialecto del estándar ECMAScript. Se define como orientado a objetos, basado en prototipos, imperativo, débilmente tipado y dinámico.

Se utiliza principalmente en el desarrollo web para añadir interactividad a las páginas, validar formularios, crear animaciones, y mucho más.

¿Qué es el DOM? +

DOM (Document Object Model) es una interfaz de programación para documentos HTML y XML. Representa la estructura del documento como un árbol de objetos, permitiendo a los programas acceder y manipular el contenido, estructura y estilo del documento.

Con JavaScript podemos modificar el DOM para crear páginas web dinámicas e interactivas.

¿Qué es Event Delegation? +

Event delegation es una técnica en JavaScript donde en lugar de agregar event listeners a elementos individuales, agregamos un solo event listener a un elemento padre. Este listener analiza los eventos que "burbujean" desde los elementos hijos.

Ventajas: mejor rendimiento, funciona con elementos dinámicos, menos consumo de memoria.

¿Qué son las Promesas en JavaScript? +

Las promesas son objetos que representan la terminación o el fracaso eventual de una operación asíncrona. Permiten manejar operaciones asíncronas de manera más limpia que los callbacks anidados.

Una promesa puede estar en uno de estos estados: pendiente, cumplida o rechazada.

¿Qué es JSON? +

JSON (JavaScript Object Notation) es un formato de intercambio de datos ligero y fácil de leer y escribir para humanos, y fácil de parsear y generar para máquinas.

Se basa en un subconjunto del lenguaje JavaScript, pero es independiente del lenguaje. Muchos lenguajes de programación tienen capacidad para leer y generar JSON.
